Task 1: Perform Basic Mathematical Operations
Problem Statement
This program:

Takes two numbers as input from the user.

Performs basic mathematical operations (Addition, Subtraction, Multiplication, Division) based on the user's choice.

Displays the result of the chosen operation.

How to Use
Run the program in a Python environment.

Enter two numbers when prompted.

Provide a mathematical symbol (+, -, *, /) to perform the desired operation.

The program will display the result of the operation. If an invalid symbol is entered, it will notify the user.

Example Output
Enter the 1st number: 5
Enter the 2nd number: 3
Enter the symbol (+, -, *, /): *
15
